# Changelog

- Каждый релиз требует changelog до Gate B.
- Язык: русский.
- Источник: реальный diff относительно предыдущего релизного tag; commits использовать только как навигацию.
- Описывать пользовательский эффект и то, что изменилось, а не внутреннюю механику.
- Для `russian.xml` суммировать добавленные, изменённые и удалённые строки, группируя крупные изменения.
- Для metadata, scripts и CI описывать результат для установки, совместимости, сборки или публикации.
- Не включать служебный шум и не придумывать изменения.
- Если пользовательских изменений нет, использовать формулировку «техническое обновление» и назвать реальный технический эффект.
- Формат release-сообщения: версия, краткий changelog, ссылка на release если она существует или выводится из repository URL.
