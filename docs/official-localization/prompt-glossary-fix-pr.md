# Prompt: Apply Glossary Translation Fixes And Prepare PR

Используй этот промт, когда у тебя уже есть JSON с предложенными исправлениями перевода.

## Инструкция

Ты работаешь в репозитории локализации BG3.  
Нужно применить предложенные исправления к `Mods/DnD 5.5e AIO Russian/Localization/Russian/russian.xml`, затем подготовить pull request.

Порядок действий:

1. Прочитай JSON с предложенными исправлениями.
2. Для каждого `contentuid` замени только текст соответствующего узла `<content>`.
3. Не меняй другие строки.
4. Сохрани XML в корректном формате.
5. Запусти проверку XML:
   `python scripts/validate-translation-xml.py -XmlPath "Mods/DnD 5.5e AIO Russian/Localization/Russian/russian.xml"`
6. Проверь diff и убедись, что изменены только нужные `contentuid`.
7. Подготовь коммит с кратким русским сообщением.
8. Запушь ветку.
9. Открой PR в `main`.
10. В описании PR кратко перечисли, какие группы терминов были приведены к глоссарию.

## Ограничения

- Не меняй `contentuid` и `version`.
- Не меняй плейсхолдеры, `LSTag`, HTML-переносы и числа.
- Не придумывай новые переводы вне JSON-входа.
- Если хотя бы один элемент нельзя применить безопасно, остановись и сообщи, какие `contentuid` требуют ручной проверки.

## Ожидаемый итог

В конце верни:

1. список изменённых `contentuid`;
2. результат валидации XML;
3. ссылку на PR.
