# ТЗ: независимая проверка перекрёстных подсказок

Проведи независимое ревью PR с перекрёстными подсказками `LSTag` в русской
локализации DnD 5.5e AIO. У тебя есть доступ к репозиторию: не доверяй выводам
автора PR и проверяй изменения по исходникам проекта и контексту описаний.

## Цель

Проверить, что в описаниях умений, заклинаний, пассивных эффектов, состояний,
предметов и других сущностей ссылки добавлены на реальные игровые понятия и
ведут к правильной цели. Одновременно убедиться, что обычные слова и название
самой описываемой сущности не превращены в лишние ссылки.

## Обязательные проверки

1. Просмотри каждое изменение `russian.xml` и сопоставь его с английским текстом,
   владельцем описания и актуальными `SpellData`, `PassiveData`, `StatusData`,
   `InterruptData`, `Skills` и `RootTemplates` родительского мода.
2. Для каждого нового тега проверь три вещи: это действительно ссылка на другую
   игровую сущность; `Type` правильный; `Tooltip` указывает именно на нужную
   сущность, а не на одноимённый вариант другой способности или состояния.
3. Проверь падеж и границы видимого текста. Тег должен охватывать полный термин:
   например, «Высшая невидимость», а не только «невидимость».
4. Различай действие, заклинание, состояние, ресурс и пассивный эффект. Особое
   внимание: `Рывок`, `Скрыться`, `Порча`, `Невидимость`, `Высшая невидимость`,
   `Слепота`, `Сон`, `Бардовское вдохновение`, `Толчок`, `Оберег от оружия`.
5. Проверь исправленные старые теги `AbilityCheck`, `SavingThrow`, характеристики
   и модификаторы: подсказка должна быть привязана к русскому термину, а не к
   слову, оставшемуся на позиции английского оригинала.
6. Проверь канонические русские термины: `КС`, `КБ`, `ОЗ`, `временные ОЗ`,
   `внеочередная атака`, навык `Внимание`.
7. Отдельно проверь предметы: их короткие описания находятся в `RootTemplates`,
   а механические эффекты могут быть вынесены в связанные пассивные эффекты,
   заклинания и состояния. Отсутствие прямой ссылки в кратком описании предмета
   само по себе не является ошибкой.
8. Не предлагай ссылки только по совпадению слова. В частности, `гадалка`,
   `странник`, `тень`, `магия`, а также `ярость` внутри названия другой черты
   требуют контекстного доказательства. Физическая тень и уровень освещённости —
   не состояние духа `SPIRITS_SHADE`; обычная магия — не навык `Магия`.
9. Проверь, что не потерян ни один `Type + Tooltip`, присутствовавший в английском
   оригинале, и что русские добавления не создали повреждённый или вложенный
   `LSTag`.

## Воспроизводимые проверки

```powershell
python scripts/audit-tooltip-links.py
python -m pytest scripts/tests/test_audit_tooltip_links.py scripts/tests/test_apply_reviewed_tooltip_links.py -q
python scripts/validate-repo.py --mode pre-commit
git diff --check origin/main...HEAD
```

Для полного каталожного прохода передай `audit-tooltip-links.py` актуальные
каталоги распакованных `Stats/Generated/Data` и конвертированных `RootTemplates`
родительского мода через `-StatsPath` и `-RootTemplatesPath`.

## Формат ответа

Сначала перечисли только доказанные проблемы по приоритету. Для каждой укажи
`contentuid`, текущий тег, ожидаемый `Type:Tooltip`, контекст исходной сущности и
почему текущая ссылка неверна или пропущена. Затем отдельно дай итог по воротам:

- потери исходных целей подсказок: PASS/FAIL;
- неверные привязки тегов к русским словам: PASS/FAIL;
- корректность новых целей по контексту: PASS/FAIL;
- ложные лексические ссылки: PASS/FAIL;
- тесты и валидатор репозитория: PASS/FAIL.

Если доказанных проблем нет, напиши это явно. Не считай сам факт расхождения с
английскими тегами ошибкой: часть русских подсказок намеренно добавлена там, где
английский оригинал не содержит полезной перекрёстной ссылки.
